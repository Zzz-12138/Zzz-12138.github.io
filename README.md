# Yuhan Zhao — Academic Homepage

This folder contains a concise standalone academic homepage drawing on the
[Plain Academic](https://github.com/mavroudisv/plain-academic) layout used by
Julius Hermelink and the restrained publication design of
[Hao Cheng's homepage](https://haoche.ng/).

## Contents

- `index.html` — responsive homepage with embedded CSS and selected publications
- `avatar.jpg` — profile photograph
- `Yuhan-Zhao-CV.pdf` — downloadable English CV
- `LICENSE.txt` — upstream Plain Academic BSD-2-Clause license

The page can be opened directly in a browser. To publish it with GitHub Pages,
place these files at the root of a public repository named
`YOUR-GITHUB-USERNAME.github.io`.

## Before publishing

Add any public profile links you want visitors to see, such as GitHub, Google
Scholar, ORCID, DBLP, or LinkedIn. No links were guessed from the résumé.
